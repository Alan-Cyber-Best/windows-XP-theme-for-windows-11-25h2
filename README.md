⚠️ Важно: создайте точку восстановления

Перед установкой тем оформления, изменением системных файлов или применением модификаций через Windhawk, ThemeToolSharp (TTS), Open-Shell и RetroBar рекомендуется создать точку восстановления Windows.

Некоторые модификации могут вызвать проблемы с интерфейсом, меню «Пуск», панелью задач или совместимостью после обновления Windows.

Как создать точку восстановления:

Нажмите Win + R.

Введите SystemPropertiesProtection и нажмите Enter.

Выберите системный диск (обычно C:).

Если защита системы выключена, включите её.

Нажмите «Создать…», укажите название, например Before Nintows Customization, и подтвердите создание.

Если после установки модификаций возникнут проблемы, можно попробовать удалить последнюю модификацию или воспользоваться восстановлением системы.

Обратите внимание: точка восстановления не заменяет резервную копию личных файлов и не гарантирует отмену всех изменений. Перед серьёзными модификациями рекомендуется дополнительно сохранить важные данные.

Используйте инструменты на свой страх и риск и проверяйте совместимость с вашей версией Windows. ⚠️ Important: Create a System Restore Point

Before installing themes, modifying system files, or applying customizations through Windhawk, ThemeToolSharp (TTS), Open-Shell, or RetroBar, it is strongly recommended to create a Windows System Restore Point.

Some modifications may cause issues with the user interface, Start menu, taskbar, or compatibility after Windows updates.

How to create a restore point:

Press Win + R.

Type SystemPropertiesProtection and press Enter.

Select your system drive (usually C:).

If System Protection is disabled, enable it.

Click Create..., enter a name such as Before Nintows Customization, and confirm.

If problems occur after installing modifications, try uninstalling the latest modification or using System Restore.

Please note: A restore point does not replace a backup of your personal files and cannot guarantee that every change will be reversed. Before making major modifications, back up your important data separately.

Use these tools at your own risk and verify compatibility with your version of Windows.
